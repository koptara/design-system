# Local design-system subset

Copied from the author's existing Smmify component library for this submission. All required source, styles and assets are included here. There are no imports from the original project.

Only the used components and their transitive source dependencies are retained. Color tokens and supported variants of those components are kept to avoid introducing visual regressions. Input, select, menu and FAQ component styles are omitted.

Runtime dependencies: React, Radix UI, class-variance-authority, cn, lucide-react and Sonner. Their package licenses remain in the installed packages. This directory does not require a CSS generation step.
